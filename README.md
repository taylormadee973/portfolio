# Dominic Taylor — Portfolio

A static portfolio website, ready for GitHub Pages.

## Publish for free

1. Sign in at https://github.com and create a **public** repository named `portfolio` (or another name).
2. Select **Add file → Upload files**. Upload `index.html` and `style.css` from this folder (not the ZIP itself), then **Commit changes**.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**. Choose **main** and **/(root)**, then **Save**.
5. Wait a few minutes and visit `https://YOUR-USERNAME.github.io/portfolio/` (substitute your GitHub username and repo name).
